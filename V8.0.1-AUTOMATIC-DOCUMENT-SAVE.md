# v8.0.1 — Automatic Document Save

- Persists every successfully opened or imported document immediately in browser storage.
- Automatically uploads eligible document text to the signed-in account after library metadata sync.
- Re-importing an older metadata-only library item now attaches and saves its text automatically.
- Removes obsolete instructions referring to a hidden “Save text to account” control.
- Keeps the existing 5 MB uncompressed account-document limit.
