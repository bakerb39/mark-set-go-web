# v6.2.6 PDF Import

## Supported imports
- EPUB / EPUB3
- Text-based PDF
- UTF-8 TXT

## PDF behavior
- Uses Mozilla PDF.js in the browser.
- The original PDF is not uploaded to the application server.
- Extracts selectable text one page at a time.
- Displays page-by-page progress.
- Inserts `[PDF Page N]` markers into the Reader text.
- Reads PDF metadata for the title when available.
- Preserves PDF outline entries and page metadata in the document source.
- Supports password prompts for protected PDFs.
- Rejects image-only or scanned PDFs when too little text is found.
- Limits PDF imports to 100 MB.
- Imported PDF text uses the existing local Reader-session and document cache.

## Current limitation
OCR is not included in this release. Scanned PDFs are detected and reported
instead of being opened as an empty or unusable text.
