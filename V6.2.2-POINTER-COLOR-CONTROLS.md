# v6.2.2 Pointer Color Controls

- Removes the Mark, Set, Go! photo pointer.
- Keeps the existing Mark pointing text-style pointer.
- Adds a pointer color picker.
- Pointer color appears only when Pointing Guide is selected.
- Supports Hand, Underline, Caret, Reading Bar, and Mark pointing.
- Pointer color is saved with reader state and mirrored in fullscreen.
