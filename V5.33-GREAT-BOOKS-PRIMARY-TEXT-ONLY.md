# v5.33 Great Books: Primary Text Only

Great Books import now rejects non-primary material.

Validation before opening a candidate:
- stronger title/author match
- minimum full-text word count
- detects common summary/study-guide/synopsis language
- rejects short excerpts/catalog extracts
- continues to the next library candidate automatically
- only opens the Reader after a candidate passes primary-text validation

The goal is that **Find & Import Edition** loads the actual work, not a summary or excerpt.
