# v5.21 Great Books + Bible Study

## Great Books
- Expands the existing Great Books Library to follow the 1990 60-volume list supplied by the user.
- Groups cards by volume and includes individual work/author-group entries.
- Removes Suggested Music from Great Books cards.
- Adds **Import public-domain edition** for each entry using the existing Project Gutenberg integration.
- Adds a Grokipedia search link using title + author for a more precise destination.
- Adds **Study / Great Ideas**, powered by a new AI study-guide endpoint.
- Study guides use original syntopical-reading prompts; they do not reproduce Britannica's Syntopicon text.

## Bible Study
- Adds **Bible Study** under Discover.
- Uses the Free Use Bible API through server-side proxy routes.
- Loads the service's available English translations dynamically.
- Supports translation, book, chapter, and optional side-by-side translation comparison.
- Can load a selected chapter into the normal Mark, Set, Go! Reader.
- Adds AI **Study / Great Ideas** for the selected chapter.
- Adds a contextual Grokipedia link.

## Navigation
- Adds a persistent **Reader** action to the top navigation for returning to the current reader.

## AI Study
- Adds POST `/api/study-guide`, using `OPENAI_API_KEY`.
- Generates overview, context, Great Ideas, study questions, and syntopical connections.
- Bible study prompts are instructed to stay grounded in the supplied passage and distinguish observation from interpretation.
