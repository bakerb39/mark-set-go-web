# Classic Guides — Modern Guide Length Standard

This patch changes **guide text only**. It does not modify Reader JavaScript, navigation, layout CSS, right-click behavior, companion behavior, or any MutationObserver code.

## Preservation rule

Existing guide content was preserved. The longer Iliad material was left intact because it was already within the Modern Guide benchmark. Existing Odyssey book-by-book and play scene-by-scene sections were retained; expansion was added around them rather than replacing or shortening them.

All guides retain the existing Reader action markers, including Discuss, Great Ideas, Action Center, Quiz, and Buy Original.
