# v7.7.16 — Cloud Productivity & Random Notes

## Added
- PostgreSQL-backed Random Notes page under My Library & Collections.
- Large expandable writing area with created and updated timestamps.
- Paste, drag/drop, and upload support for inline PNG, JPEG, GIF, and WebP images.
- Up to five images per note, one MB per image.
- Pin, favorite, tags, and related-book links.
- Create, edit, delete, email one note, or email all Random Notes.
- Random Note images are sent as email attachments.
- Durable account email preferences in PostgreSQL.
- Email preference status and last-saved indicators in Action Center.
- Clear cloud-document labels: Library entry saved vs. Document saved to account.
- Continue/Resume can load cloud text when the local browser copy is unavailable.

## Migration
Run `npm run db:migrate` once to apply `004_random_notes_email_preferences.sql`, then return the Render Start Command to `npm start`.

## Protected reader architecture
ReaderEngine, VirtualRenderer, playback cursor/viewport, pause/resume, Book Pages, session restoration, and reader rendering are unchanged.
