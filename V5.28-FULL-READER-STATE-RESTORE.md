# v5.28 Full Reader State Restore

Returning to Reader now retains the complete reader configuration.

Restored:
- reading mode
- WPM
- words shown
- meaningful chunks
- Focus Anchor on/off
- Focus Anchor position
- Focus Anchor size
- Focus Anchor color
- Focus Anchor bold setting
- font family
- font size
- theme
- Bionic Reading
- Book Pages
- illustration mode
- logical reading position
- running/paused state

Important fixes:
- Captures a complete control snapshot before leaving the Reader, while controls still exist in the DOM.
- Return to Reader no longer calls `captureReaderControls()` against a non-reader screen and accidentally substitutes defaults.
- Fullscreen controls are synchronized with restored normal-reader controls.
- Book Pages receives a post-render geometry/reflow pass and is returned to the spread containing the saved logical reading position.
