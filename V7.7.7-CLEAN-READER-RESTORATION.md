# Version 7.7.7 — Clean Reader Restoration

This release restores the complete reader subsystem from the last user-confirmed stable reader build, version 7.6.8, while retaining the PostgreSQL, Clerk authentication, and private beta access shell from version 7.7.3.

## Protected reader baseline

The following were restored directly from v7.6.8 without reader-logic edits:

- `app.js`
- `public/app.js`
- `public/reader/`
- `modules/reading/`
- `public/modules/reading/`

All reader patches introduced after v7.6.8 were excluded.

## Retained platform features

- PostgreSQL foundation and migrations
- Clerk authentication
- Private beta access gate
- Clerk modal visibility correction

## Safeguard

`READER-CORE-SHA256SUMS.txt` records the protected reader baseline. Before future releases, run:

```bash
sha256sum -c READER-CORE-SHA256SUMS.txt
```

A checksum failure means protected reader code changed and requires explicit review.
