# v7.0.0 Reader Continuity Foundation

## Core rule
No interface choice or page visit may change the canonical reading word unless
the user explicitly navigates within the text.

## Reader continuity
- Adds one central ReaderContinuity authority.
- Saves the exact word before all navigation away from the Reader.
- Protects the exact word after reading/display control changes.
- Covers mode, words per step, meaningful chunks, Focus Anchor, pointer,
  typography, theme, bionic text, Book Pages, and illustration controls.
- Restores virtualized documents around the correct word.
- Restores the correct Book Pages spread.
- Resumes only after the word is restored.
- Saves on navigation, pagehide, and tab hiding.

## Page continuity
- Remembers window and internal-panel scroll positions.
- Returning to Browse, Library, AI, Help, Progress, and other pages restores the
  previous page position.

## PDF retained
All PDF import functionality from v6.2.6 remains included:
- PDF.js browser extraction
- page markers and progress
- password support
- scanned-document detection
- local storage and Reader integration
