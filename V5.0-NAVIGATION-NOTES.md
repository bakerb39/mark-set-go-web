# v5.0 navigation fix

- Corrected wheel polarity for the user's mouse so wheel-down goes to the previous spread and wheel-up advances.
- Manual Previous/Next now temporarily suspends the active reading timer.
- The logical word position is synchronized only after two animation frames, after the new spread and any column reflow are committed.
- The requested spread is reasserted after reflow so the highlighter cannot immediately pull the viewport forward again.
