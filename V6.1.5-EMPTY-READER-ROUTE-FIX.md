# v6.1.5 Empty Reader Route Fix

## Root cause
The empty Reader screen still used legacy route values:

- `import`
- `all`
- `library`

The current router expects:

- `upload`
- `unified-library`
- `my-library`

Those legacy values fell through to the generic reader loader and produced
**Reading unavailable / Unknown reading selection**.

## Fix
- Import Book now opens the import page directly.
- Search All Libraries now opens the unified library search page directly.
- My Library now opens the personal library page directly.
- Added backward-compatible aliases so stale cached markup using the old values
  will still work.
