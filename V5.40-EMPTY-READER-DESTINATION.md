# v5.40 Empty Reader Destination

- The top Reader action and Home Open Reader button no longer appear to do nothing when no text is active.
- If there is an active reader, Reader still returns to that text with its preserved state.
- If there is no active text, Reader opens a dedicated empty-reader screen.
- Empty Reader clearly says no text is loaded and offers:
  - Import Book / Text
  - Read from URL
  - Search All Libraries
  - Great Books
  - Bible Study
  - My Library
- Persistent saved sessions are still not silently reconstructed; Resume Last Reading remains an explicit Home action.
