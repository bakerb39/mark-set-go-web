# v5.12 Focus Anchor controls and fullscreen layout

- Added Focus Anchor color choices: Green, Blue, Amber, Red, Purple.
- Added optional Bold anchor letter setting; default remains normal weight.
- Added the same color and bold controls to fullscreen Options and synchronized them with the main reader.
- Balanced the upper/lower fixation marker dimensions and reduced excess lower overlay padding.
- In fullscreen, Focus Anchor is placed in a stable top band and the reader reserves clearance beneath it so book text starts below the anchor rather than underneath it.
- Normal-window Focus Anchor remains draggable; fullscreen uses the stable top placement for a cleaner reading experience.
- Focus Anchor color/bold preferences are persisted with the reader session.
