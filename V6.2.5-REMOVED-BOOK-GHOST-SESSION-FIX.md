# v6.2.5 Removed Book / Ghost Session Fix

## Where Crime and Punishment came from
The app stores related reading information in several independent places:

1. My Reading list
2. Cached downloaded book
3. Reading Progress
4. Locally stored document text
5. Active in-memory Reader snapshot
6. Persistent IndexedDB Reader session
7. Lightweight Resume Last Reading metadata

The Remove button previously cleared only items 1 and 2. A saved Crime and
Punishment session could therefore remain in IndexedDB and return through
Resume Last Reading.

## Fix
When a reading-list book is removed, the app now clears all matching references:

- Reading-list entry
- Cached download
- Active Reader snapshot
- Persistent IndexedDB Reader session
- Resume Last Reading metadata
- Reading Progress entry
- Locally stored text
- Live Reader engine state

Only records matching the removed book's document ID or normalized title are
cleared. Other books remain untouched.
