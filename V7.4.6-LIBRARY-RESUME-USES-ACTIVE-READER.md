# V7.4.6 — Library Resume Uses Active Reader

- Fixed the My Library → Resume Reading path for the currently active text.
- When the selected library item matches the active reader session, Resume Reading now calls the exact same `renderCurrentReader()` path used by Return to Reader.
- Prevents the stored-document loader from rebuilding the reader and resetting the viewport to the beginning.
- Includes a document ID match and a title/text fallback for older records whose IDs differ.
