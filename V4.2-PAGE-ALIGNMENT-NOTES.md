# v4.2 Book Page Alignment

- Corrected two-page spread stride to account for the CSS column gap.
- Prevented cumulative horizontal drift when the reading helper advances through a book.
- Book Pages now remain vertically locked to the top of the page viewport so a complete page stays visible.
- Horizontal overflow remains available for page turning while vertical overflow is suppressed in Book Pages mode.
- Existing v4.1 page counter and controls are retained.
