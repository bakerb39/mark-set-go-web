# v5.4 Media Match

- Replaced the ambiguous reader "Adaptation score" action with a contextual Media Match control.
- Media Match offers two explicit choices: Music score and News video.
- News/feed/article readings default Media Match to News video.
- Book and other text readings default Media Match to Music score.
- News video searches YouTube using the exact reading headline/title plus its source when available.
- Music score preserves the existing adaptation/cinematic-score recommendation logic.
- Fullscreen Options contains the same Media Match selector and action and stays synchronized with the normal reader controls.
- Reading Mood remains a separate music recommendation.
