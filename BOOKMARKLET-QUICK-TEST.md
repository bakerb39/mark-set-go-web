# Bookmarklet quick test

1. Deploy this branch to the Render test service.
2. Open **My Library → Read Anything**.
3. Select **Show Bookmarklet**.
4. Drag **Read with Mark** to the desktop browser bookmarks bar.
5. Visit a readable article and click the bookmarklet.
6. A new Mark, Set, Go! tab should open and load the captured article into the existing reader.

For iPhone Safari, create any bookmark, edit it, rename it `Read with Mark`, and replace its address with the bookmarklet code shown inside the Read Anything screen.
