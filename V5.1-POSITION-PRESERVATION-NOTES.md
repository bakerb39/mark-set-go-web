# v5.1 Position Preservation

- Preserves the current visible/logical word when reader options cause a re-render or layout reflow.
- Applies to mode changes, Bionic Reading, Center Focus Anchor, Meaningful Chunks, Illustrations, Book Pages, font family, and text size.
- Book Pages restores the spread containing the captured word after page geometry is recalculated.
- Fullscreen mirrored controls inherit the same behavior because they dispatch through the main controls.
