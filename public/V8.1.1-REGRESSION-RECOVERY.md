# v8.1.1 — Regression Recovery

This release disables the two new interception-based synchronization adapters introduced in v8.1.0 while retaining the proven v8.0.1 cloud document behavior.

## Fixed

- Book Pages no longer resets to the beginning when selected.
- Restored book-page vertical position instead of reopening at the top.
- Removed the storage interception path that could interfere with unrelated account features, including email preferences.
- Retained automatic document upload, cloud library metadata, and the existing stable resume implementation.

## Architecture decision

The v8.1.0 adapters patched `Storage.prototype` globally and attempted to synchronize progress independently of the established reader restore pipeline. That introduced competing state writers. The adapters remain in the package for audit purposes but are no longer loaded by the application. A future cloud refactor should integrate through explicit reader events and server APIs rather than global storage interception.
