# v8.1.0 — Cloud Foundation and Architecture Stabilization

## Purpose

This release consolidates account-worthy state behind a shared synchronization layer without redesigning the protected reader engine or adding major user-facing features.

## Storage policy

### Cloud authoritative, locally cached

- Imported document text (dedicated document API)
- Library metadata (dedicated library API)
- Reading position (dedicated progress API)
- Reading activity and goals
- Reading notes and bookmarks
- Saved definitions and comprehension results
- Reading lists and Syntopicon saves
- Action Center settings and items
- User links and book music assignments
- Reader defaults (preferences API)

### Local/device only

- Fullscreen and temporary panel state
- Animation and renderer state
- Network response caches
- Temporary import processing
- Authentication/session identifiers
- Offline cache copies of cloud documents

## Database write policy

- Local changes are immediate.
- Account state and reading progress are debounced for 20 seconds.
- Writes occur only after a meaningful value changes.
- Pending changes retry after connectivity returns.
- Tab hiding and page exit request a final flush.
- Documents are uploaded only on import/change, not during reading.

## Conflict policy

- Timestamped account-state records use newest-write-wins.
- Reading progress prefers the newer record; equal timestamps preserve the farther reading position.
- Cloud application is guarded so restored values do not loop back as new edits.
- Oversized general state values are excluded; large documents continue through the dedicated compressed document endpoint.

## New modules

- `cloud-sync-manager.js`: centralized account-state queue, debounce, retry, offline behavior, and conflict resolution.
- `cloud-progress-sync.js`: dedicated cross-device reading-position synchronization.

## Compatibility

Existing direct localStorage calls remain functional. The synchronization manager observes approved account-worthy keys, allowing gradual module extraction without destabilizing the reader.
