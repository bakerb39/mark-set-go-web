# v5.25 Syntopicon + Study Languages

- Adds **Syntopicon · Great Ideas** under Discover.
- Includes a broad Great Ideas vocabulary plus custom ideas/questions.
- Allows selection of multiple Great Books and the most recently loaded Bible chapter.
- New `/api/syntopicon` performs comparative syntopical analysis:
  shared terms, source positions, agreements, disagreements, distinctions, study questions, and a reading path.
- Exact Bible chapter text is supplied to the comparison when available; Great Books without an excerpt are explicitly treated as work-level orientation.
- Syntopical analyses can be saved locally.
- Adds analysis-language choice for Syntopicon.
- Great Books now exposes a Study Language selector for AI study guides.
- Bible Study now exposes:
  - Bible-language filtering across all available API translations
  - Study/display language
  - Translate Displayed Chapter
  - Restore Source Translation
- Bible chapter translation uses the existing browser Translator API first and the server translation fallback second.
- The source Bible translation remains unchanged when the displayed text is translated.
