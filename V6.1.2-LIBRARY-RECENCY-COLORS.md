# v6.1.2 My Library Recency Colors

My Library book covers now use subtle colors based on the most recent reading date:

- Green: read today
- Blue: read during the last 7 days
- Violet: read during the last 30 days
- Amber: read during the last 90 days
- Burgundy: read more than 90 days ago
- Slate: no recorded reading date

The primary current book and Continue Reading cards both use the same system.
Hover text and accessible labels explain each book's recency category.
