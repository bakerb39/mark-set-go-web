# v6.1.4 Windows-Style List View

The List option is now a genuine compact text/details view rather than a smaller card view.

- Plain text rows
- Compact row height
- Minimal borders
- No book covers or large artwork
- Title, author, and metadata aligned on the left
- Compact actions aligned on the right
- Hover highlight similar to a desktop file browser
- Group headings behave like expandable folders
- Tiles remain unchanged as the visual card presentation

Applied generically to list-enabled catalog and library pages.
