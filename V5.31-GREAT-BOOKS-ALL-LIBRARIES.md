# v5.31 Great Books: Search All Libraries

Great Books import no longer searches Project Gutenberg alone.

For each Great Book, **Find & Import Edition** now:
1. Searches the unified library endpoint across:
   - Standard Ebooks
   - Internet Archive
   - Open Library
   - Wikisource
   - Project Gutenberg
2. Uses title + author and fallback search queries.
3. Scores results for title/author relevance.
4. Prefers directly readable and curated/proofread editions.
5. Tries readable candidates one by one until one actually opens.
6. If one provider fails, automatically continues to the next candidate/provider.
7. Shows the source currently being tried.
8. If only a discovery/borrowing result is available, offers the closest catalog link instead of pretending the text can be imported.

Open Library remains useful for discovery but is not treated as directly readable unless the unified source marks a result readable.
