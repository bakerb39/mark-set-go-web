# v4.8 Pagination correction

- Book Pages now keeps one canonical spread index for buttons, wheel, highlighter, TOC, resize and fullscreen.
- Mouse wheel gestures are debounced so a single gesture turns exactly one two-page spread.
- Per requested direction: wheel up advances; wheel down goes back.
- Book page turns use exact horizontal positions instead of smooth intermediate scrolling, eliminating forward/backward jitter.
- A ResizeObserver recalculates the two-page geometry whenever the actual reader width changes, including fullscreen and pane-size changes, while preserving the current logical spread.
- Other reading modes are unchanged.
