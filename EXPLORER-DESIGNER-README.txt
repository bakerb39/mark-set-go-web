Explorer Visual Designer v1.0

Install:
- Extract this ZIP at the repository root.
- It contains a public/ folder.
- Existing Explorer visual/theme files are not replaced except index.html is updated to load the designer.

Use:
1. Select Explorer in Profile.
2. Open the Reader or another Explorer page.
3. Click the floating “✦ Design” button.
4. Click a live element or choose it from Layers.
5. Adjust sliders/colors. Artwork can also be dragged directly while Design mode is open.
6. Click Save design to persist the design in this browser.
7. Export creates a JSON file that can later be baked into the app as the shared/default design.

Safety:
- Does not modify Reader engine, reading modes, timing, WPM, Book Pages, Flash, Pac-Man, or pointer code.
- No MutationObserver.
- Reset Explorer removes only Visual Designer overrides.
