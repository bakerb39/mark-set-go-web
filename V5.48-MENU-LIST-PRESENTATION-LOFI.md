# v5.48 Menu, List Presentation, and LoFi Fix

## Navigation
- Renames **Library** to **My Library**.
- Places **Search All Libraries** as the first My Library option.
- Renames **Discover** to **Browse** to distinguish public/curated content from the user's own library.
- Keeps My Reading, Progress & Awards, imports, and URL reading under My Library.

## LoFi
- LoFi Music now performs a current YouTube search rather than relying on one fixed/stale video ID.
- The player can use the first playable result and offer another result when available.

## List-heavy pages
Adds reusable view controls with saved browser preferences:
- Tiles / List
- Collapse All / Expand All where pages contain grouped sections

Applied to:
- Search All Libraries results
- My Reading List
- Great Books volumes
- Vocabulary Builder
- News, Sports & Interests sources
