# v5.29 Bible Entire Book Fix

The Read Entire Book action was expecting a `/complete` payload with a `chapters[]`
shape. The Bible service is reliably chapter-oriented, so some translations returned
no usable `chapters[]`, causing the Reader to receive an empty string and display
"No readable text."

Fix:
- Read Entire Book now uses the same chapter endpoint already proven by Load Chapter.
- It reads the selected book's known chapter count.
- Fetches up to four chapters concurrently.
- Validates every chapter before opening the Reader.
- Builds a clean continuous book with chapter headings and a chapter TOC.
- Shows chapter-loading progress.
- If a chapter genuinely fails, Bible Study remains open and shows the specific error
  instead of navigating to an empty Reader.
