PUBLIC/INDEX.HTML — feature/ask-mark-premium-phase-1

1. Make sure these are loaded in <head>:

<link rel="stylesheet" href="/msg-chat.css?v=1.1.0">

<script defer src="/msg-chat.js?v=1.1.0"></script>

IMPORTANT: load this AFTER experience-themes.js:
<script defer src="/msg-chat-integration.js?v=1.1.0"></script>


2. Add this top-level navigation button immediately BEFORE Profile:

<button class="top-level-nav-button" data-action="msg-chat" type="button" title="Open Mark, Set, Go! Chat"><span class="nav-icon" aria-hidden="true">◫</span> Mark, Set, Go! Chat</button>


3. Do NOT add a custom click handler to this button.

That is what allows workspace-experiment.js to intercept data-action="msg-chat" and
open the chat in the existing right-side workspace frame when:
- a Reader is open, and
- Profile > Open pages in workspace is enabled.

If workspace is off, msg-chat.js renders it as a normal full app page.


4. Themes menu:
msg-chat-integration.js removes the old top-level Themes launcher after
experience-themes.js initializes. Theme selection remains in Profile.
