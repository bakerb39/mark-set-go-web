# Mark, Set, Go! v4.4

## Book Pages only
- Uses a deterministic two-page viewport only while Book Pages is enabled.
- Calculates usable reader width and divides it into two equal page columns separated by the configured gap.
- The highlighter no longer performs incremental horizontal scrolling in Book Pages.
- When the active word enters the next spread, the viewer moves exactly 1–2 → 3–4 → 5–6, etc.
- The bottom page status is a real control; clicking it advances one spread. Keyboard Enter/Space also works.
- Recalculates page geometry on window resize without affecting other reading modes.

## Browser translation
- Prefers Chrome's built-in desktop Translator API when available.
- Downloads language packs on demand and reports progress in the existing translation status area.
- Translates long text in bounded chunks to avoid oversized requests.
- Word-to-English translation also prefers the browser Translator API.
- Preserves the existing `/api/translate` and `/api/translate-word` routes as fallbacks.
- No server changes were made.
