# v5.15 Comprehension MVP

- Adds server-side `POST /api/comprehension` using the OpenAI Responses API.
- API key is read only from `OPENAI_API_KEY`; it is never exposed to browser code.
- Model defaults to `gpt-5.6-luna` and can be overridden with `OPENAI_COMPREHENSION_MODEL`.
- Uses Structured Outputs / JSON Schema for exactly four multiple-choice questions:
  recall, main idea, inference, deeper understanding.
- Reader adds **Check Comprehension** in normal and fullscreen controls.
- Uses text read since the previous check, capped at 900 words; first check uses up to the previous 750 words.
- Requires at least 120 words.
- Scores locally and saves comprehension %, WPM, and effective WPM to browser localStorage.
- Reading Progress now includes comprehension average and recent checks.
