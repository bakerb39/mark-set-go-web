# v5.7 EPUB Import

- Added client-side EPUB/EPUB3 import to the existing Upload workflow.
- EPUB ZIP contents are unpacked in the browser using ZIP central-directory parsing and the browser DecompressionStream API.
- Reads META-INF/container.xml and the OPF manifest/spine to preserve publication reading order.
- Uses EPUB 3 nav.xhtml when available and NCX as a fallback.
- Resolves TOC entries to real word positions in the extracted text, including fragment IDs when available.
- Reader prefers the EPUB-provided TOC rather than heuristic text heading detection.
- TXT import remains supported.
- EPUB source file itself is not sent to the server.
