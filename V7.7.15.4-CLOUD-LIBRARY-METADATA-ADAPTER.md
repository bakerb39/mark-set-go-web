# Mark, Set, Go! v7.7.15.4

## Cloud Library Metadata Adapter

This release adds a separate PostgreSQL-backed adapter for My Library metadata.

### Included

- Loads authenticated account-library metadata through the existing cloud API.
- Upserts local library metadata to PostgreSQL without saving reading progress.
- Adds an account-sync indicator to My Library.
- Marks matching local books as saved to the account.
- Displays cloud-only metadata records separately when the text is not available on the current device.
- Supports removing cloud metadata without deleting local reading text.
- Keeps the cloud cache in memory and uses only existing session/browser records as migration input.

### Protected architecture check

The following files are byte-for-byte unchanged from v7.7.15.3:

- `app.js`
- `public/app.js`
- `public/reader/ReaderEngine.js`
- `public/reader/VirtualRenderer.js`

No changes were made to:

- playback cursor or viewport-anchor logic;
- pause/resume;
- Book Pages;
- fullscreen;
- reader session capture or restoration;
- reader rendering or scrolling.

### Database

No database migration is required. This adapter uses the existing `library_books` API and table introduced by the cloud account foundation.
