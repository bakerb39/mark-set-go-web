# v5.9 Mode/Option Position Preservation

- Uses the reader engine word index as the canonical position for timed/guided modes.
- Prevents mode changes and Focus Anchor/layout toggles from inferring word 0 from a newly rebuilt DOM.
- Two-column mode still derives position from its self-paced scroll location.
- Long virtualized documents restore around the saved word instead of rendering every preceding word.
- Running/paused state is preserved across supported option and mode changes.
