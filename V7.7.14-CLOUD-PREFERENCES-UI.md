# Mark, Set, Go! v7.7.14 — Cloud Preferences UI

## Scope

This release connects the existing reader preference controls to the authenticated PostgreSQL account preferences API.

## Behavior

- Loads `preferences.readingDefaults` after Clerk authentication and account bootstrap.
- Applies saved defaults when a reader view is opened.
- Saves changes from the existing Reading and Display controls with a short debounce.
- Preserves unrelated preference fields when saving.
- Exposes `window.MarkSetGoCloudPreferences` for focused testing.

## Protected architecture

The following files were not modified:

- `app.js`
- `public/app.js`
- `reader/ReaderEngine.js`
- `public/reader/ReaderEngine.js`
- Cursor and viewport-anchor separation logic

The integration is isolated in `cloud-preferences.js` and `public/cloud-preferences.js`.

## Console verification

After signing in and opening a book:

```js
window.MarkSetGoCloudPreferences.capture()
```

Change a reader preference, wait about half a second, and then verify:

```js
(await window.MarkSetGoCloud.bootstrap()).preferences.readingDefaults
```
