# v5.34 Pagination Word-Anchor Reflow

Fixes Book Pages jumping to unrelated content when the reader geometry changes.

Root cause:
- Previous reflow logic preserved the old spread number.
- A spread number is not stable when viewport width changes because text repaginates.

New rule:
- The logical word index is the canonical reading location.
- Before a layout change, capture the current word.
- After layout/reflow, calculate which NEW spread contains that word.
- Navigate to that new spread without changing the logical word position.

Covered layout changes:
- browser/window resize
- Marks & Contents open/close
- Reader Controls open/close
- dragging either side-pane divider
- entering fullscreen
- leaving fullscreen
- ResizeObserver-driven reader width changes

Repeated ResizeObserver events share one pending word anchor so intermediate geometry
changes cannot progressively drift the reader to another page.
