MANUAL PACE — HOLD TO MOVE

Horizontal controls now behave like a physical guide:

- Hold Right Arrow: continuously move forward at assigned WPM.
- Release Right Arrow: stop immediately.
- Hold Left Arrow: continuously move backward at assigned WPM.
- Release Left Arrow: stop immediately.
- If both are briefly held, the most recently pressed direction wins.
- Releasing one while the opposite remains held continues in the opposite direction.
- Native keyboard repeat is ignored; Manual Pace's WPM timer determines cadence.

Vertical controls remain:
- Up Arrow: one visual line up per press.
- Down Arrow: one visual line down per press.

Spacebar:
- pauses active Manual Pace movement.
- resumes only if a horizontal arrow is currently still held.
- does not override release-to-stop behavior.

WPM=0:
- horizontal arrows can be held but no automatic movement occurs.
- Up/Down still work.

No renderer, pagination, or right-click code changed.
