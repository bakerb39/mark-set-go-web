# Mark, Set, Go! v8.0.0 — Unified Document Manager

## Purpose
Provides one external document-resolution gateway for Home, My Library, Continue Reading, Reading Notes source links, and other library entry points without changing the protected reader implementation.

## Resolution order
1. Existing browser text: the verified application handler opens it normally.
2. Cloud document text: Document Manager retrieves it through the authenticated account API and passes it to the existing `renderReaderWithText` input boundary.
3. Metadata only: the user receives an accurate message explaining that only the library entry is stored and that the document must be re-imported and saved to the account.

## UI clarification
Cards distinguish among:
- Document saved to account
- Library entry saved
- Available on this device
- Local only

## Protected architecture
The following are unchanged:
- ReaderEngine
- VirtualRenderer
- playback cursor and viewport-anchor implementation
- pause/resume
- Book Pages
- session capture and restoration
- reader rendering logic

The manager does not alter reader state. It resolves a text source and invokes the existing document-opening boundary.
