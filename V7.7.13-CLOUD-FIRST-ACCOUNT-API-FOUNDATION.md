# Version 7.7.13 — Cloud-First Account API Foundation

## Added

- Authenticated PostgreSQL APIs for account preferences.
- Authenticated PostgreSQL APIs for library books.
- Authenticated PostgreSQL APIs for reading progress.
- Account bootstrap endpoint for loading preferences, books, and progress in one request.
- Browser cloud-data service exposed as `window.MarkSetGoCloud`.
- Migration `002_cloud_account_foundation.sql`.

## Protected reader architecture

The verified v7.7.12 reader implementation was not modified. Persistent reading progress stores these values independently:

- `playback_index` — Pointing Guide playback cursor.
- `viewport_anchor_index` — document viewport anchor.
- `viewport_offset_px` — viewport offset from the anchor.

Viewport persistence must never overwrite the playback cursor.

## Deployment

Run the database migration after deployment:

```bash
npm run db:migrate
```

No existing account data is deleted.

## Scope

This release establishes the authenticated cloud API and client service. Existing application screens can be connected to these APIs category by category without changing the protected reader engine.
