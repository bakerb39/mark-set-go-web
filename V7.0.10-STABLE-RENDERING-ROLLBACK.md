# V7.0.10 Stable Rendering Rollback

- Removed the bounded/sliding long-book rendering introduced in versions 7.0.8 and 7.0.9.
- Removed scroll-triggered window replacement and automatic position correction that could cause blank space and self-scrolling.
- Restored the stable reader rendering behavior from version 7.0.7.
- Retained EPUB embedded-image support, fullscreen listener cleanup, lightweight progress saving, throttled status updates, WPM below the viewer, and reader bottom-spacing fixes.

This release intentionally prioritizes stable manual scrolling over experimental long-book virtualization.
