# V7.0.1 — EPUB Embedded Image Support

## Summary

EPUB imports now preserve embedded images and display them through the reader's existing chapter illustration system.

## Changes

- Reads `<img>` and SVG `<image>` references from EPUB XHTML spine documents.
- Resolves image paths relative to each chapter file.
- Extracts JPEG, PNG, GIF, WebP, and SVG resources from the EPUB archive.
- Converts embedded resources to browser-safe data URLs.
- Associates each image with the corresponding EPUB navigation heading.
- Automatically enables **Illustrations → Chapter openings** when imported artwork is present.
- Leaves PDF extraction, text tokenization, pagination, and reader-position continuity unchanged.

## Validation target

The illustrated Project Gutenberg edition of *Dracula* should import with 27 chapter illustrations and display them at the chapter openings in supported reading modes.
