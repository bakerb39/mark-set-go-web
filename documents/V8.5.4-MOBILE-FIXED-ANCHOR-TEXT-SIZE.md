# v8.5.4 — Fixed Top Anchor and Mobile Text Size

## Changes

- Removed the mobile anchor placement selector.
- Mobile focus anchor is always fixed at the top.
- Reader text begins below the anchor band rather than underneath it.
- Added mobile text-size controls from 12 px through 24 px, defaulting to 14 px.
- Tightened focus-anchor overlay vertical spacing on desktop and mobile.
- Preserved the 36 px red anchor and one-word Highlight defaults.

## Protected reader architecture

No reader engine, playback cursor, pagination, resume, viewport-anchor, or Book Pages implementation files were modified.
