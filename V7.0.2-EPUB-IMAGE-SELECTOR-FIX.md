# Version 7.0.2 — EPUB Image Selector Fix

- Fixed the EPUB import crash caused by the invalid CSS selector `image[xlink:href]`.
- SVG image references are now detected through safe attribute checks, including namespaced XLink `href` values.
- Standard EPUB `<img src>` and SVG `<image href>` artwork remain supported.
- PDF import and reader-position continuity are unchanged.
