# Version 7.7.15 — Bounded TOC Navigation

## Approved scope

This release changes only the performance path used by distant Table of Contents navigation in normal scrolling reader modes. The user explicitly authorized this performance-critical change.

## Problem

A distant TOC selection called `ensureWordsRendered(index + 100)`, which synchronously created every word node from the beginning of a large document through the selected destination. A jump to a late chapter could create tens of thousands of DOM nodes and freeze the browser.

## Change

- Distant TOC jumps now render a bounded 2,400-word window around the destination.
- Virtual scrolling spacers preserve an approximate full-document scrollbar without materializing preceding text.
- Scrolling near a virtual window edge shifts the bounded window by 800 words.
- Normal incremental rendering remains unchanged until a distant TOC jump activates the bounded mode.
- Book Pages behavior was not changed.
- Playback cursor and viewport anchor remain separate.

## Browser test

A headless Chromium test used a synthetic 100,000-word document and jumped directly to word 60,000.

- Target word found: yes
- Rendered word nodes after jump: 2,400
- Rendered range: 58,800–61,200
- Jump execution time in the test environment: approximately 142 ms
- No need to create the preceding 60,000 word elements

## Protected architecture

The playback cursor/viewport-anchor separation remains in place. This release intentionally modifies `VirtualRenderer.js` and the narrow TOC jump path only.
