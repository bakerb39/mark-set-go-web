# v7.7.15.5 — Cloud Document Adapter

## Scope
- Adds opt-in compressed document-text storage in PostgreSQL.
- Limits each document to 5 MB of UTF-8 text.
- Shows original and compressed sizes in My Library.
- Loads cloud text through an external adapter and the existing document-open boundary.
- Leaves all protected reader architecture unchanged.

## Migration
Run `npm run db:migrate` once to apply `003_account_documents.sql`.

## Cost strategy
- Text storage is opt-in per book.
- Public/reloadable books do not need to be stored automatically.
- Oversized documents are rejected rather than silently consuming database capacity.
- The adapter boundary can later target S3-compatible object storage.
