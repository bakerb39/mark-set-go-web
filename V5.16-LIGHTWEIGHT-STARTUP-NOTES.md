# v5.16 Lightweight Startup

- Removed automatic reconstruction of the previous book during app launch.
- Startup now renders the lightweight home screen immediately.
- Added **Resume Last Reading**. The full saved reader session is read from IndexedDB only after the user explicitly clicks Resume.
- Added a tiny `markSetGoReaderSessionMetaV1` localStorage record containing only title, word position, total words, document ID, and save time.
- Future launches can show the last title/progress without loading or cloning the entire book.
- Existing saved sessions remain compatible; if metadata does not exist yet, Resume Last Reading still attempts to open the previously saved session.
- Comprehension MVP remains unchanged and does no work until Check Comprehension is clicked.
