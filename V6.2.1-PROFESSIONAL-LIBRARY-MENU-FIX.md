# v6.2.1 Professional My Library Menu Fix

## Root cause
The navigation dropdown inherited overflow and custom scrollbar behavior from
other application components. This produced clipped content, horizontal and
vertical blue scrollbars, and unusable nested flyouts.

## Fix
- Replaces nested flyouts with one clean, fixed-width dropdown.
- Removes all dropdown scrolling and clipping.
- Uses clear sections for Library, Collections, and Insights.
- Adds short descriptions only for primary destinations.
- Uses a compact two-column collection grid.
- Automatically closes navigation after selecting an item.
- Closes open menus when clicking outside.
- Uses a mobile-safe fixed dropdown on narrow screens.
