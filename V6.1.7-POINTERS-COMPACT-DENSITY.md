# v6.1.7 Pointer Refinements and Compact Density

## Pointer Guide
- Pointer Style is hidden unless Pointing Guide is selected.
- Caret is larger and more visible.
- Existing Mark pointing text pointer remains available.
- Adds a separate Mark, Set, Go! pointer using the existing animated Mark image.
- The photo pointer is intentionally large enough to be recognizable and humorous.

## Compact Density
- Reduces application-page heading sizes, card heights, padding, and vertical gaps.
- Makes Browse, My Library, AI, Help, Progress, and catalog pages fit more content above the fold.
- Keeps Reader text sizing and reading viewport typography unchanged.
