# Iliad Classic Guide corrective patch

This patch restores the Iliad Classic Guide to the existing Reader flow while preserving the complete original Classic Guide reference content and retaining the expanded 24-book detail.

## Preserved content
- At a Glance
- all 16 original reference sections
- all 14 character entries
- all 11 Great Ideas, questions, and Great Conversation connections
- all 24 expanded book-by-book entries
- all 12 quiz questions and explanations
- all 3 action plans
- all 4 visual-study references

## Reader parity with Modern Guides
The Classic Guide is opened directly in the existing Reader and uses the existing guide action renderer, so it includes the same inline action markers used by Modern Guides: Buy Original, Discuss, Great Ideas, Add to Action Center, and Quiz.

The guide is persisted through the existing guide document/library path with `classicGuide:true`, allowing My Library to label it `Classic Guide` while reusing the proven Modern Guide persistence behavior.
