# v8.1.2 — Full Rollback to the Verified v8.0.1 Baseline

This release removes the v8.1 cloud foundation experiment completely.

## Why v8.1.1 did not fix the regressions

v8.1.1 still loaded `cloud-sync-manager.js` and `cloud-progress-sync.js` from `index.html`. Those scripts continued patching `Storage.prototype.setItem` and continued introducing a second reading-progress synchronization path. Therefore the claimed rollback was incomplete.

## What this release does

- Restores every application file from the verified v8.0.1 package.
- Removes all references to the v8.1 sync manager and progress sync adapter.
- Restores the exact v8.0.1 Book Pages, resume, and email behavior.
- Changes browser script version strings to `8.1.2` only to force cache refresh.
- Retains automatic account document saving introduced in v8.0.1.

No architecture refactor is included. Stabilization will resume only after the baseline regressions are confirmed resolved.
