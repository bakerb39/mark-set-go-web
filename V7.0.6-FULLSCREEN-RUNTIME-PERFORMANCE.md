# V7.0.6 — Fullscreen Runtime Performance

- Replaced the repeating full-reader snapshot with a lightweight resume-position heartbeat.
- Full book/session snapshots still occur on meaningful user actions and lifecycle events.
- Throttled reader status and WPM DOM painting during animation-driven reading modes.
- Avoided duplicate status DOM writes when the displayed value has not changed.
- Stabilized Book Pages `ResizeObserver` handling so sub-pixel/layout noise cannot repeatedly trigger page reflow.
- Preserves EPUB images, PDF import, reader continuity, fullscreen cleanup, and below-viewer WPM placement.
